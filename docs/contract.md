# LumaLatch implementation contract

Purpose: friends on one Tailscale network watch the same Jellyfin item through Chrome. Media stays on Jellyfin; this app relays only state. One host, in-memory rooms, invite-capability access. No Jellyfin credentials collected. Windows/macOS/Linux Node + Chrome.

Release 0.2.0 adds a portable Windows WinForms launcher and bundled Node runtime, plus Mac runtime archives and a command launcher. Chrome identity is fixed by manifest public key; launcher derives and allows that exact origin. The packaged desktop flow replaces manual runtime installation and per-user ID exchange. Source CLI remains supported. The server accepts `stop` on its owning process stdin for clean desktop shutdown. Release artifacts, runtime downloads, profiles and checks stay inside this project (`dist` / `.cache`).

## Server API and protocol

ESM server/index.js exports async createPartyServer({host='127.0.0.1',port=0,allowedOrigins}) returning {server,wss,url,close}, close async. Import has no side effects. CLI uses TAILSCALE_IP (must be an assigned Tailscale IPv4/IPv6), PORT default 8787, JELLYFIN_ORIGINS comma-separated allowlist. Never default CLI to all interfaces. WebSocket path /party. HTTP /health returns JSON only. Reject unexpected browser Origins; tests explicitly allow fixture origin. Tests may omit Origin for Node ws clients. Message validation, size/rate limits, room bounds, expired empty rooms, host disconnect ends room.

Messages JSON. Server welcome {type:'welcome',clientId}. Client {type:'create'}; server {type:'created',roomId,permissions,state,role:'host'}. Client {type:'join',roomId}; server {type:'joined',roomId,permissions,state,role:'guest'}. Room ID crypto random >=128 bits; possession grants guest access, never host authority. Single room membership/socket. Host authority inferred from socket only.

Permissions {playback:false,subtitles:false,quality:false} initially. Host sends {type:'permissions',permissions}; server broadcasts {type:'permissions',permissions}. Reject non-host changes. Errors {type:'error',code,message}. Room termination {type:'ended'}; participant changes {type:'members',count} optional.

Clock: server sends {type:'probe',t0} immediately and every 5 seconds. Client echoes {type:'probe',t0,t1:Date.now()}. Server calculates RTT and offset (server time minus client time) from midpoint, prefers lowest RTT samples; sends {type:'clock',offset,rtt}. Reject bogus or unsolicited probes. Clients can send {type:'ping',clientTime}; server returns {type:'pong',clientTime,serverTime} optionally. Offset convention is fixed: estimatedServerNow=Date.now()+offset.

Playback client sends {type:'state',action:'play'|'pause'|'seeked'|'ratechange'|'sync',position,paused,rate,clientTime:Date.now()}. Validate finite position>=0, 0.25<=rate<=4, boolean paused. Host may send every action; guests require playback permission, including sync. Server calculates event server timestamp from sender offset, bounds stale/future timestamps, projects playing position to server receipt time, broadcasts to ALL clients {type:'state',action,position,paused,rate,serverTime,sequence}. Latest authoritative state retained for late join. Receiver projects position forward by elapsed estimated server time only while playing. Monotonic sequence; suppress echo from programmatic media changes, retain periodic host sync every 2 seconds. A pause applies immediately before seeking. Autoplay rejection must be visible. Host's state is authoritative on joining/reconnecting; leave and reconnect must not silently rehost.

Subtitles/quality messages {type:'setting',kind:'subtitles'|'quality',value:string}. Host or authorized guest only. Broadcast validated setting, no arbitrary selectors/code. Local Jellyfin subtitle/quality access must respect permissions. Real Jellyfin menu adapters should use its existing controls, never pretend a data attribute changes stream quality. Report unsupported Jellyfin UI explicitly.

## Extension UI/test contract

MV3. Background service worker owns WebSocket, avoiding insecure ws from HTTPS page contexts. Content script uses runtime Port; extension UI injects into Jellyfin player via MutationObserver and survives SPA video replacement. Use Shadow DOM and accessible labelled controls; textContent for untrusted data. Overlay label LumaLatch. Stable accessible controls: Signaling server (URL input), Connect, Create Party, Party ID (input), Join Party, Leave Party, Copy invite. Host toggles labels Guest playback, Guest subtitles, Guest quality. Status element role=status. Invite is a Jellyfin URL including lumalatchRoom and lumalatchServer query fields; do not leak Jellyfin API/access tokens. The content script parses invite; require explicit connect/join. Never grant all-site access permanently by default: popup Enable on this Jellyfin site requests optional host permissions and dynamically registers content scripts. A test can register scripts through extension service worker and grant permissions with Chromium launch where needed. Prefer manifest content_scripts on http/https with optional scoped injection if practical; coordinate changes to this contract.

## Validation

Node protocol tests cover host/guest state, clock, malformed payloads, permission denial, late join, host disconnect. Playwright uses two independent headless Chromium browser processes, a real playable local media fixture, production unpacked MV3 extension and production WebSocket server. Assert real HTMLVideoElement play then host pause: guest pause event timestamp minus host pause event timestamp <=50 ms, timestamps captured in browser handlers (no Playwright polling duration). No mocked pause or WebSocket. Tests also cover seek/rate and permissions, errors logged fail tests. Browser binaries, profiles and artifacts under project .cache/test-results. Record measured samples. 50 ms is a local test acceptance criterion, not a WAN guarantee.
